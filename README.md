# Reinforcement Learning Projects

Q-learning and Deep Q-learning examples for Tic-Tac-Toe.

- `src/` — Python scripts
- No separate local dataset is required; the examples learn from game states / self-play.

## Setup
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```
